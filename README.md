# Custom Analysis Code

This repository contains the custom code used for data analysis in the associated research study.

## Contents

The repository includes code for:

* Data preprocessing and preparation
* Statistical analysis
* Model development and evaluation
* Generation of results and figures

## Requirements

The analyses were performed using R. Required R packages are specified within the corresponding scripts.

## Reproducibility

The code is provided to facilitate transparency and reproducibility of the analyses reported in the manuscript. Due to data privacy and/or ethical restrictions, the underlying dataset is not publicly available.

## Usage

The scripts should be run in the order indicated by their filenames or comments within the code. Input data should be prepared according to the variables and formats specified in the scripts.

## Citation

If using or referring to this code, please cite the associated research article.
